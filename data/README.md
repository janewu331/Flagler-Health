# Data

The original dataset was provided by Flagler Health and contains patient-level healthcare and communication records. The underlying data are not included in this public repository.

The analysis used four primary sources:

- Patient health metrics, including pain, mobility, mood, and sleep
- Enrollment and status-change records
- Patient–Medical Assistant message transcripts
- Insurance claims containing procedure and diagnosis codes

The analysis scripts expect authorized local copies of the required processed data files in this directory. The repository `.gitignore` prevents common patient-level data formats from being committed.
